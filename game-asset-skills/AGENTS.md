# game-asset-skills — AGENTS.md

## Overview

This package bundles skills for generating consistent AI game-art prompts (character/sprite, icon, background/tileset) for solo devs using chat-based AI tools. Independent of `development-skills`, `srs-skills`, and `virtual-team-skill`.

## Quick Start

Open `game-asset-skills/` in Claude Code. Skills appear in autocomplete.

## Commands

| Command | Description |
|---------|-------------|
| `/game-asset-prompt` | Generate a style-consistent, ready-to-paste image-gen prompt for a game art asset |

## Copy to Another Project

```bash
cp -r game-asset-skills/skills/game-asset-prompt <your-project>/skills/game-asset-prompt
```
